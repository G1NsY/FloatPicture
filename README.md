**图片格式支持（Picture format）**：jpg/jpeg、png、webp、bmp、gif（将作为静态图）、HEIC/HEIF。
**语言支持（Language）**:  简体中文与英语（Simplified Chinese and English）

### 产品定位

FloatPicture 是一款面向摄影、短视频、绘画和内容创作者的悬浮参考图工具，核心定位是**手机拍摄构图与姿态对齐辅助工具**，同时也能作为平板绘画的线稿参考工具。

它不只是把图片悬浮在屏幕上，还可以将手机拍摄或导入的照片快速转换为醒目的彩色线稿。用户可将线稿叠加在相机、录像、绘画或其他应用上方，一边创作、一边对照和调整。通过改变参考图的大小、位置、角度与透明度，可以快速对齐人物姿势、主体位置和画面构图，让参考照片直接成为创作画面中的辅助线。


### 核心功能

- **彩色线稿生成**：快速提取照片中人物、物体和场景的边缘，支持红、绿、蓝、黑、白五种线稿颜色，并可选择保留 18% 灰色背景或透明背景，减少完整照片对创作画面的遮挡。
- **悬浮拍摄参考**：参考图可以显示在相机、录像或其他应用上方，拍摄时无需反复切换查看。
- **姿势辅助对齐**：根据线稿调整人物头部、肩部、手脚和身体姿态，适合模仿参考动作。
- **构图辅助对齐**：帮助确定主体在画面中的位置、大小、倾斜角度及留白范围。
- **绘画与写生参考**：将照片线稿悬浮在绘画应用上方，辅助临摹、结构观察和比例检查。
- **透明度调节**：在看清参考线稿的同时保留相机或画布内容，方便比较偏差。
- **自由缩放、旋转与定位**：根据不同屏幕、机位、拍摄距离和画布尺寸调整参考层。
- **手势调整与保存**：支持单指移动、双指缩放和双指旋转，并可通过通知栏保存最后的调整状态；保存后还可自动锁定手势，避免误触。
- **单图与多图悬浮**：可选择一次只显示一张参考图，或让多张图片同时悬浮。
- **多参考图管理**：保存多张动作、构图或绘画参考，通过通知栏快速切换、显示、隐藏和保存参数。
- **参数保留替换**：更换参考图片时保留原有位置、缩放、旋转和透明度，方便连续创作。
- **另存为副本**：复制当前图片及其全部变换信息，再独立替换副本图片，适合快速制作相同布局的参考图。
- **参考层快速显示与隐藏**：需要检查真实画面或画布时，可以临时隐藏参考层，再快速恢复。


### 应用场景

1. **复刻参考照片**：拍摄同款姿势、人物比例和画面构图时，直观比较实际画面与参考图之间的偏差。
2. **降低拍摄沟通成本**：模特、摄影师或单人自拍时，可以按照线稿快速调整动作和站位，减少反复描述。
3. **提高独立创作效率**：一个人使用三脚架拍摄时，也能判断自己应该站在哪里、做什么动作。
4. **保持系列内容一致**：适合固定机位、每日记录、穿搭对比、商品展示、前后对比及需要重复构图的短视频。
5. **辅助短视频动作设计**：将分镜截图或动作关键帧作为参考，帮助复现人物站位、镜头构图和动作幅度。
6. **辅助商品与静物摆放**：拍摄商品、餐饮、手工作品或桌面布置时，按照线稿调整物体的位置和大小。
7. **辅助绘画临摹与写生**：将手机照片快速生成线稿参考图，帮助观察轮廓、结构、透视和比例关系。

> **把参考图叠加到创作画面上，让构图、站位、动作和线条都有迹可循。**

*目前 FloatPicture 主要提供视觉对照与手动调整，不具备自动人像识别、姿势正确性判断或相机自动控制功能。


# 功能说明(Feature Guide)

### 基本功能 - 参数控制
1. **设定图片大小 (Resize the picture)**
可根据手机屏幕大小自由调整照片的长宽比（缩放比率精确到0.001），支持滑块拖动和直接输入长宽像素，也可锁定原始比率调整。
2. **设定位置 (Set position)**
可设置悬浮图片在屏幕上的位置，支持滑块拖动和数字输入。
3. **设定图片角度 (Set Angle)**
可通过拖动滑块以45°为单位快速步进调整，也可手动输入精确的数值调整（最小单位精确到1°）。
4. **设定图片透明度 (Set transparency)**
范围从0-1(最小单位精确到0.01)。

### 高级功能 - 手势控制
- 侧边栏“全局设置”→“高级功能”
可以在应用外通过手势控制图片的大小、位置、旋转，变换后也可以选择保存到图片的属性。
开启“保存手势信息到图片”后，可点击通知栏保存按钮，将当前图片的位置、缩放和旋转录入图片信息；建议同时开启“**保存后锁定”**，在保存成功后自动关闭移动缩放和旋转，避免误触。

###  其他功能
- 自定义导入的图片名称
- 可保留已有参数直接**替换图片**
- 可另存**图片副本**，结合替换图片可以快速新增相同参数的图片
- 可设置导入时的图片质量：需要在导入图片之前设置好参数，图片导入后不可更改，初始设置为80%。

### 【新功能】
- **快速生成彩色线稿参考图(Create Colored Line-art Reference)**
可将手机拍摄或导入的照片快速转换为红、绿、蓝、黑或白色线稿参考图，并调整线条范围与对比度。生成的线稿可配合悬浮透明度使用，为拍摄构图、人物姿态对齐、绘画临摹和比例检查提供参考。
- **通知栏控制(Notification Controls)**
点击通知栏的**前后箭头**，可快速切换上一张或下一张；点击**小眼睛**，快速显示或隐藏当前图片；启用保存手势信息后，点击**保存图标**，快速锁定保存当前位置、缩放和旋转。

## 2.0.4 更新说明

- 手机拍摄或导入的照片可快速生成线稿参考图。
- 新增线稿颜色切换，支持红、绿、蓝、黑、白五种颜色。
- 颜色切换后自动刷新预览。
- 首次生成线稿时保留原始参考图，之后切换颜色时始终从原图重新生成，避免在线稿上重复处理。
- 新增线稿背景选项，可保留 18% 灰色背景，也可移除背景并生成透明线稿。
- 将“生成彩色线稿参考图”移动到图片设置中的“通用设置”分类。
- 主界面图片名称下方分两行显示缩放、位置和旋转摘要，例如 `S(1.000,1.000)` 和 `P(100,132)  R(45.0°)`。
- 将位置设置移动到“图片控制设置”，并将相关名称精简为“大小”“位置”“角度”“透明度”；四个调整弹窗统一使用 80% 不透明度背景。
- 新增单图/多图悬浮模式；单图模式下打开新图片会自动关闭上一张图片。
- 全局高级功能支持单指拖动、以双指位置为中心缩放、独立双指旋转。
- “允许图片溢出屏幕”移动到全局“通用设置”；启用手势旋转时会自动开启该选项。
- 可通过通知栏按钮保存当前手势调整，并在保存后自动锁定以防止误触；未保存的手势变化会在关闭图片后恢复。
- 通知栏显示当前选中的图片，小眼睛按钮用于显示或隐藏当前图片。
- 图片设置新增“另存为副本”，复制图片及全部变换信息，方便保留布局后替换图片。
- 修复取消导入图片后仍提示“成功添加窗口”的问题。
- 优化中英文说明，补充拍摄与绘画参考用途。
